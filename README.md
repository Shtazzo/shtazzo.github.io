# shtazzo.github.io

Personal website of Emanuele Donno — plain HTML/CSS/JS, served by GitHub Pages from `gh-pages`.

- `index.html` — the whole site (styles and scripts inline)
- `images/profilo.jpg` — profile photo (`images/archivio/` keeps old ones)
- `cv.html` — CV page (A4 print layout; visitors save it as PDF via the browser, no phone number on purpose)
